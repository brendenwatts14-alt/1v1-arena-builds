# FPS ARENA — builds

This repository holds nothing but game builds. You don't need to download
anything from it by hand except the installer.

## Install

1. Download **[FPSArenaSetup.exe](https://github.com/brendenwatts14-alt/1v1-arena-builds/releases/latest/download/FPSArenaSetup.exe)**
   and run it.
2. **Next**, pick a folder (the default needs no administrator), **Install**,
   **Finish**. It adds FPS ARENA to the Start menu and the desktop and opens the
   launcher, which downloads the game (about 4.5 GB the first time).
3. When the button says **PLAY**, play.

Windows will say *"Windows protected your PC"* the first time, because the
installer and the launcher aren't code-signed: click **More info**, then
**Run anyway**. When you host a match for the first time, Windows Firewall asks
about the game: allow it, or nobody can join you.

(Rather not install? **[ArenaLauncher.exe](https://github.com/brendenwatts14-alt/1v1-arena-builds/releases/latest/download/ArenaLauncher.exe)**
on its own works too: put it in a folder of its own and run it; the game goes
into `Game\` beside it.)

## Updates

Open FPS ARENA. When there is a new version the button says **UPDATE**, and
it downloads only what changed — no reinstalling. Otherwise it says **PLAY**.

- Close the game before updating.
- An update that gets interrupted picks up where it left off.
- **Verify and repair files** fixes a broken install without re-downloading it.
- Your settings, name and loadouts are never touched by an update.

## Uninstall

*Settings > Apps > FPS ARENA > Uninstall*. It keeps your settings and
loadouts unless you untick that.
