# 1v1 Arena — builds

This repository holds nothing but game builds. You don't need to download
anything from it by hand except the launcher.

## Install

1. Download **[ArenaLauncher.exe](https://github.com/brendenwatts14-alt/1v1-arena-builds/releases/latest/download/ArenaLauncher.exe)**
   (one file, nothing else to install).
2. Put it in a folder of its own, e.g. `C:\Games\1v1 Arena\`. The game installs
   into `Game\` beside it.
3. Run it and press **INSTALL** (about 4.5 GB the first time).

Windows will say *"Windows protected your PC"* the first time, because the
launcher isn't code-signed: click **More info**, then **Run anyway**. When you
host a match for the first time, Windows Firewall asks about the game: allow it,
or nobody can join you.

## Updates

Open the launcher. When there is a new version the button says **UPDATE**, and
it downloads only what changed — no reinstalling. Otherwise it says **PLAY**.

- Close the game before updating.
- An update that gets interrupted picks up where it left off.
- **Verify and repair files** fixes a broken install without re-downloading it.
- Your settings, name and loadouts are never touched by an update.
